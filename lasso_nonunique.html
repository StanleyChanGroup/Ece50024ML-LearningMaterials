What you're seeing

Setup: A = [1, 1] (one observation, two parameters). The prediction is x+y, so any (x,y) on the line x+y = c gives identical loss. Loss contours are diagonal tubes — flat in the [1,1] direction.

When the flat face of the ℓ₁ diamond aligns with the flat face of a loss tube, the touching set is a whole segment, not a single point — giving infinitely many solutions.

Key insight: Every point on the orange segment achieves the exact same objective value c*. This is consistent with Exercise 6 parts (a) and (b) — all solutions share the same predictions Aθ = r and the same ℓ₁ norm ‖θ‖₁ = r. The solution vector θ itself is not unique.
