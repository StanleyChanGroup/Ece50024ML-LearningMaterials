HW3 Exercise 6 — Optimality of LASSO

ECE 50024 · Machine Learning · Proof walkthrough + visual intuition

The problem

The d-dimensional LASSO minimizes:

L(θ) = ‖Aθ − y‖² + λ‖θ‖₁

You need to show the solution is unique by proving two things:

a
If β ≠ θ are both global minimizers → Aθ = Aβ

Any two minimizers must produce identical predictions.

b
If β ≠ θ are both global minimizers → ‖θ‖₁ = ‖β‖₁

Any two minimizers must have identical ℓ₁ norms.

⚠️ The title says "LASSO solution is unique" — but what's actually unique is the predicted values Aθ and the penalty ‖θ‖₁, not necessarily the vector θ itself.

Part (a) Proving Aθ = Aβ

The proof strategy is contradiction. Assume Aθ ≠ Aβ and derive something impossible.

Step 1 — Form a midpoint

Pick any γ ∈ (0,1) and define:

α = γθ + (1−γ)β

Then by linearity of A:

Aα = γAθ + (1−γ)Aβ

Step 2 — Apply convexity

Since f(z) = ‖z‖² is strictly convex and Aθ ≠ Aβ (by assumption):

‖Aα − y‖² = ‖γ(Aθ−y) + (1−γ)(Aβ−y)‖² < γ‖Aθ−y‖² + (1−γ)‖Aβ−y‖²

The ℓ₁ norm is merely convex (not strict), so:

‖α‖₁ ≤ γ‖θ‖₁ + (1−γ)‖β‖₁

Step 3 — Combine

L(α) = ‖Aα−y‖² + λ‖α‖₁ < γL(θ) + (1−γ)L(β) = γc* + (1−γ)c* = c*

Step 4 — Contradiction

α achieves a value strictly below c*, the supposed global minimum. Impossible. So our assumption Aθ ≠ Aβ must be false.

✓ The key is strict convexity of ‖·‖². The solution note in the handout only uses weak convexity (≤), which gives ≤ c* — not a contradiction. The strict inequality from ‖·‖² is what makes the proof work.

Part (b) Proving ‖θ‖₁ = ‖β‖₁

From part (a) we know Aθ = Aβ, so:

‖y − Aθ‖² = ‖y − Aβ‖²

Both θ and β achieve the same total objective value c*, so:

‖Aθ−y‖² + λ‖θ‖₁ = c* = ‖Aβ−y‖² + λ‖β‖₁

Since the squared loss terms are equal, the ℓ₁ terms must also be equal:

λ‖θ‖₁ = λ‖β‖₁ → ‖θ‖₁ = ‖β‖₁
✓ Part (b) is a simple algebraic consequence of part (a).
